# SUPERMAIL

## Web Development Lab 

### Objective

To design and develop a responsive web page using HTML, CSS, and modern layout techniques with interactive elements.

---

# Project Overview

This project is a Gmail-inspired responsive mail interface developed using HTML, CSS, and JavaScript. It demonstrates modern web development concepts such as Flexbox, CSS Grid, responsive layouts, hover animations, and DOM interaction.

---

# Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome Icons

---

# Software Required

- Visual Studio Code
- Google Chrome
- Live Server Extension

# Step 7: Responsive Design

Media Queries were implemented for:

## Desktop

- Full sidebar
- Four-column mail layout

## Tablet

- Smaller sidebar
- Icons only

## Mobile

- Sidebar moves above content
- Search bar becomes full width
- Mail layout becomes two-column
